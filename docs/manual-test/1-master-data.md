# Skenario Manual Testing — Master Data

## Ruang lingkup dan prasyarat

Skenario ini mencakup menu **Master Data** yang tersedia di sidebar: **Organization** (Companies, Branches, Departments, Locations, Cost Center), **Product** (Categories, Types, Brands, Models, License Types, Products), dan **Procurement** (Vendor Types, Vendors, Unit of Measure, Payment Terms, Tax). Akses menu melalui sidebar; URL yang dicantumkan adalah halaman daftar.

Siapkan company `CAA` / `PT Contoh Abadi`, branch `JKT` / `Cabang Jakarta`, department `IT` / `Information Technology`, dan lokasi `HO` / `Head Office` mengikuti [01-persiapan.md](01-persiapan.md). Untuk uji relasi, siapkan juga category `Laptop`, type `Laptop Bisnis`, brand `Lenovo` yang terhubung ke category tersebut, model `ThinkPad T14`, vendor type `LOCAL`, vendor `VND-001`, serta UOM `PCS`. Gunakan suffix kode unik bila data tersebut telah ada.

Akun yang menjalankan skenario perlu permission tulis master terkait. Seeder role `User` hanya memberi permission lihat master; gunakan Administrator atau akun dengan permission create/update/delete. Jalankan validasi pada environment uji.

## Catatan temuan saat membaca kode

- Sebagian label dan bahasa form master tidak seragam (misalnya `Add Company`, `Tambah Satuan`, `Create Tax`, dan `Add Product`). Skenario menggunakan teks tombol yang ditemukan per halaman.
- Daftar master umumnya mencari dengan kotak **Cari data...**, memakai pagination 15 baris, dan tidak memiliki aksi cetak/ekspor yang ditemukan pada halaman tersebut. Products memiliki pencarian, filter group/status, serta pilihan jumlah baris; skenario cetak/ekspor sengaja tidak ditambahkan karena tidak ditemukan aksi tersebut pada kode halaman Master Data.
- Form edit untuk code menerapkan disabled dan form create/edit memakai composable `useMasterFieldFormatting` untuk uppercase code serta Proper Case name.
- Kode route CRUD resource menyediakan index/create/store/edit/update/destroy. Category, Type, Brand, Model, License Type, dan sebagian besar master organization/procurement tidak menyediakan halaman detail/show. Products menyediakan show/detail.
- `ProcurementChannelController` dan request ada di source tetapi tidak ditemukan route atau menu aktif. Karena itu **Procurement Channel** tidak dimasukkan sebagai fitur yang dapat diuji melalui UI.
- Tidak ada bug yang diperbaiki. Relasi parent/location dan category/type/brand/model perlu diuji hanya melalui kombinasi yang tersedia di UI; request lintas relasi yang tak dapat dibentuk lewat antarmuka diberi catatan.
